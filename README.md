# Data Science, the Clojure Way

A ground-up course in the principles of data science, worked through in Clojure with Tablecloth, Fastmath, 

Tableplot and metamorph.ml. Every idea comes as a picture first, then code you write yourself, then a project where it matters.

## Contents
The course has 18 modules in five parts. Each module follows the same rhythm:
- principle first (what is true and why), 
- then a picture (a diagram or an interactive demo you can play with), 
- then code at the REPL, then exercises you check off. 

Many core algorithms are written first write by hand in plain Clojure, then we use the library version, 
so that the library is never a black box.
